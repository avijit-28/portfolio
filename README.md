## 🚀 How to Deploy on Vercel

### Method 1: Push to GitHub & Import to Vercel (Recommended)
1. Initialize a git repository and push to GitHub:
   ```bash
   cd "D:\All\python code\Portfolio"
   git init
   git add .
   git commit -m "Initial commit of new portfolio"
   git branch -M main
   git remote add origin https://github.com/avijit-28/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New..."** > **"Project"**.
4. Import your `portfolio` repository.
5. Vercel will automatically detect the static project and deploy it in seconds with a live `.vercel.app` URL!

### Method 2: Vercel CLI (1-Command Deployment)
If you have `vercel` installed:
```bash
cd "D:\All\python code\Portfolio"
vercel
```
Follow the prompt, and Vercel will generate your live production URL instantly.
